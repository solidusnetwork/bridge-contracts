# Security policy

## Report a vulnerability privately

Use GitHub's private vulnerability reporting for this repository: open the **Security** tab and choose
**Report a vulnerability**. Please do not open a public issue or pull request for a vulnerability.

A useful report names the contract and function, what you can cause with it, and a way to reproduce it. A
Foundry test is ideal. If it concerns a deployment, give the chain and the address.

## Scope

The Solidity under `src/` in this repository and the testnet deployments listed in the README.

## What happens next

The repository administrators read the report and reply to you through the advisory. Please give us time to
fix an issue before you disclose it.
